# Русификатор Dungeon Siege 2 (Steam)

Файлы смотрите в Релизах
Перевод игры выполнен с помощью **Gemini 4 Argon**.

### Установка

1. Файл `Logic.ds2res` необходимо заменить в папке игры `Dungeon Siege 2\Resources`.
2. Файл `World.ds2map` необходимо заменить в папке игры `Dungeon Siege 2\Maps`.

### Примечание

Перевод больше не будет обновляться. Если вы обнаружите ошибки или неточности в переводе, прошу прощения.

Приятной игры!
